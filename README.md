# Brightpath Automation

Демо-кейс: интерактивный лендинг для вымышленного агентства ИИ-автоматизации. Проект создан для инженерного портфолио: я выступила в роли AI Product Manager, код сгенерирован ИИ на платформе Lovable.

**Демо:** https://brightpath-automation.lovable.app/

## Что внутри
- Воронка заявок на русском языке с калькулятором стоимости
- ИИ-консультант, который предлагает сценарии автоматизации
- Тёмный интерфейс в стиле «жидкого стекла» с анимациями фона
- Адаптивная вёрстка

## Стек
React, Vite, TypeScript, Supabase, Lovable

## Моя роль
Продуктовая логика шагов воронки, UI/UX-контроль, локализация под русскоязычный B2B-рынок, публикация.

## Запуск
1. `npm i`
2. Скопируйте `.env.example` в `.env` и заполните значения
3. `npm run dev`

> Все данные на сайте демонстрационные.
