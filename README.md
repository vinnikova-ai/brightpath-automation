# Brightpath Automation

Create a modern, high-converting interactive landing page for an AI & Automation Agency. 

Design requirements:

- Futuristic minimalist dark-mode aesthetic with smooth gradients.

- Fully responsive and screen-optimized.

Sections to include:

1. Hero section with a powerful value proposition and a primary Call-to-Action button.

2. Value Benchmark & Features: A visually structured section explaining how AI tools eliminate manual work.

3. Interactive Lead Capture Form: A multi-step questionnaire that dynamically simulates calculation. All text inside this form and all inputs/placeholders must be strictly in Russian.

Russian localization for the form:

- Title: "Рассчитать стоимость автоматизации"

- Step 1: "Какую задачу нужно решить?" (Options: "Внедрить LLM/ИИ-ассистента", "Автоматизировать рутину", "Создать умный лендинг/бота")

- Step 2: Contact fields (Имя, Telegram / Email)

- Button: "Получить решение"
